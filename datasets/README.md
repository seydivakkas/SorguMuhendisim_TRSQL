# datasets/ — Veri kümesi kartları

**Ham veri git'e girmez.** Burada yalnızca kartlar ve indirme/hazırlama betikleri bulunur.

| Küme | Lisans | İzin verilen kullanım |
|---|---|---|
| TURSpider | kartta doğrulanacak | Değerlendirme |
| BIRDTurk | HF kartı: cc-by-nc-sa-4.0 | **Yalnız değerlendirme** (ADR-0009) |
| Spider / BIRD | ilgili lisanslar | Değerlendirme / karşılaştırma |
| Kurumsal sentetik set | proje içi | Değerlendirme + (ayrı bölüm) eğitim |

Her küme için `datasets/<ad>.md`: kaynak, sürüm, dosya hash'i, lisans, bölümler, bilinen
sorunlar (ör. BIRDTurk'te hücre değerleri çevrilmemiş).
